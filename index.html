Version History

MaxPlan — WO Material Planner
v1.1.4
April Week 1 2026
Latest
  • Work order status — each WO now has a status: Planned, In Progress, On Hold, Complete, or Cancelled. Status is shown as a colour-coded badge on the home screen card and in the WO header
  • Status can be changed two ways: tap the coloured status badge in the WO header, or change it inside the Edit Work Order sheet
  • Tappable WO number with ▾ triangle in the WO header — tap the WO number to open the Edit Work Order sheet directly, replacing the separate pencil button
  • WO status is included in the exported clipboard summary
  • All features from v1.1.3 retained (WO-level location & asset inheritance, Location of Work field, Rotating Asset Number, per-unit slot tracking)
v1.1.3
April Week 1 2026
Previous
  • Work order creation and edit page now includes an Asset Number field and a Location of Work field at the WO level
  • Plan items added after a WO-level location or asset number is set automatically inherit those values in the Actual tab (highlighted in purple)
  • Inherited fields remain editable per slot in the Actual tab
  • Existing plan items are unaffected when WO location/asset is later changed — delete and re-add an item to pick up updated WO values
  • Plan items show inheritance chips indicating which WO-level values they carry
  • Rotating Asset Number field renamed to clearly differentiate the unique rotating asset being issued vs the WO-level asset number
  • Location field label changed to Location of Work throughout
  • WO home cards show location and asset number if set
v1.1
April Week 1 2026
Previous
  • Rotating items now include a planned quantity field in the Plan tab
  • Actual tab shows an individual slot per planned rotating quantity — each with a unique asset number and location
  • Non-rotating items support per-unit location tracking in the Actual tab
  • Added edit work order (number, description, notes)
  • Added Notes field on work orders
  • New Summary tab with planned vs actual totals and completion percentage
  • Export / copy to clipboard
  • Reservation timestamps on every planned item (DD/MMM/YYYY 0:00am format)
  • Confirmation dialogs before deleting items or work orders
  • In-app version history page and automatic update check
v1.0
April Week 1 2026
Initial Release

Initial release of MaxPlan. Core functions:

  • Create and manage multiple work orders
  • Add non-rotating and rotating items to a Plan tab
  • Record actual quantities used for non-rotating items
  • Record issued asset numbers for rotating items
  • Fully offline-capable via service worker caching
  • Installable to phone home screen as a standalone PWA
  • All data saved locally on-device
