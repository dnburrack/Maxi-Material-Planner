MaxPlan — WO Material Planner
v1.2.1
April Week 2 2026
Latest
  • Barcode scanner completely rebuilt as a pure JavaScript Code 128 decoder — zero external dependencies, zero browser APIs beyond the camera itself, works on every browser, 100% offline
  • Fixed: previous versions relied on BarcodeDetector (Chrome/Android and iOS 17+ only) which caused the "unsupported browser" error on most iPhones; the new decoder runs its own scan logic and works on all iOS and Android browsers
  • Scanner reads frames from the live video feed, converts each row to grayscale, applies adaptive thresholding, measures bar/space run widths, quantises to Code 128 module widths (1–4), and matches against the full 107-symbol ISO 15417 Code 128 table
  • Scans 40 horizontal rows per frame and requires 2 consistent reads before confirming a result — reduces false positives
  • Decodes Code A, Code B, and Code C start codes; verifies checksum before returning
  • All v1.2 features retained
